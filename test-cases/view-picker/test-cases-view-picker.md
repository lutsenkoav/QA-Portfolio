## 1. Открытие модального окна

| **TC-ViewPicker-001** | |
|------------------------|---|
| **Название** | Проверка открытия модального окна выбора |
| **Приоритет** | High |
| **Предусловия** | 1. Открыта форма, содержащая поле View picker. |
| **Шаги** | 1. Нажать на кнопку "Выбрать" (или иконку) внутри поля View picker. |
| **Ожидаемый результат** | Открывается модальное окно с представлением (ListView/TreeView) для выбора элемента. |
| **Постусловия** | Закрыть модальное окно. |

---

## 2. Поиск и фильтрация

| **TC-ViewPicker-002** | |
|------------------------|---|
| **Название** | Проверка поиска в модальном окне View picker |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыто модальное окно View picker (TC-ViewPicker-001).<br>2. В списке есть несколько элементов. |
| **Шаги** | 1. В поле поиска ввести название существующего элемента.<br>2. Ввести частичное название.<br>3. Ввести несуществующее название. |
| **Ожидаемый результат** | 1. Список фильтруется по введённому запросу.<br>2. При частичном совпадении отображаются все подходящие элементы.<br>3. При несуществующем названии отображается сообщение "Ничего не найдено". |
| **Постусловия** | Очистить поле поиска. |

## 3. Выбор одного элемента

| **TC-ViewPicker-003** | |
|------------------------|---|
| **Название** | Проверка выбора одного элемента в View picker |
| **Приоритет** | High |
| **Предусловия** | 1. Открыто модальное окно View picker.<br>2. В списке есть элементы. |
| **Шаги** | 1. Выбрать один элемент (кликнуть по нему).<br>2. Нажать кнопку "Применить" или "Выбрать" (если требуется). |
| **Ожидаемый результат** | 1. Модальное окно закрывается.<br>2. В поле View picker отображается выбранный элемент (его название, код или другой идентификатор). |
| **Постусловия** | Очистить поле (если требуется). |

---

## 4. Выбор нескольких элементов

| **TC-ViewPicker-004** | |
|------------------------|---|
| **Название** | Проверка выбора нескольких элементов в View picker (Multi-picker) |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыто модальное окно View picker (TC-ViewPicker-001).<br>2. Мульти-выбор разрешён. |
| **Шаги** | 1. Выбрать несколько элементов (через чекбоксы или с Ctrl).<br>2. Нажать кнопку "Применить". |
| **Ожидаемый результат** | 1. Модальное окно закрывается.<br>2. В поле View picker отображаются все выбранные элементы (списком или через разделители). |
| **Постусловия** | Очистить поле. |

---

## 5. Очистка поля

| **TC-ViewPicker-005** | |
|------------------------|---|
| **Название** | Проверка очистки поля View picker |
| **Приоритет** | High |
| **Предусловия** | 1. Открыта форма с полем View picker.<br>2. В поле выбран элемент (TC-ViewPicker-003). |
| **Шаги** | 1. Нажать на крестик (или кнопку "Очистить") рядом с выбранным элементом в поле View picker. |
| **Ожидаемый результат** | Выбранный элемент удаляется из поля. Поле становится пустым. |
| **Постусловия** | Нет |

---

## 6. Отображение выбранных элементов

| **TC-ViewPicker-006** | |
|------------------------|---|
| **Название** | Проверка отображения выбранных элементов в модальном окне |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыта форма с полем View picker.<br>2. В поле уже выбран элемент (TC-ViewPicker-003). |
| **Шаги** | 1. Нажать кнопку "Выбрать" внутри поля View picker. |
| **Ожидаемый результат** | Модальное окно открывается. Ранее выбранный элемент в модальном окне подсвечен (отмечен). |
| **Постусловия** | Закрыть модальное окно. |

---

## 7. Обязательность заполнения

| **TC-ViewPicker-007** | |
|------------------------|---|
| **Название** | Проверка обязательности заполнения поля View picker |
| **Приоритет** | High |
| **Предусловия** | 1. Открыта форма с полем View picker, которое обязательно для заполнения.<br>2. Поле пустое. |
| **Шаги** | 1. Отправить форму, оставив поле View picker пустым. |
| **Ожидаемый результат** | Отображается сообщение об ошибке валидации (например, "Это поле обязательно для заполнения"). Форма не отправляется. |
| **Постусловия** | Выбрать элемент и отправить форму. |

---

## 8. Режим "только для чтения"

| **TC-ViewPicker-008** | |
|------------------------|---|
| **Название** | Проверка отображения View picker в режиме "только для чтения" |
| **Приоритет** | Medium |
| **Предусловия** | 1. Найти форму, где View picker находится в режиме "только для чтения".<br>2. В поле выбран элемент. |
| **Шаги** | 1. Обратить внимание на состояние поля.<br>2. Попытаться нажать кнопку "Выбрать" (если она отображается). |
| **Ожидаемый результат** | 1. Поле отображает выбранный элемент, но неактивно для редактирования.<br>2. Кнопка выбора неактивна или отсутствует.<br>3. Поле нельзя очистить. |
| **Постусловия** | Нет |

---

## 9. Закрытие без выбора

| **TC-ViewPicker-009** | |
|------------------------|---|
| **Название** | Проверка закрытия модального окна View picker без выбора |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыто модальное окно View picker (TC-ViewPicker-001). |
| **Шаги** | 1. Нажать кнопку "Отмена" или "Закрыть" (крестик в углу). |
| **Ожидаемый результат** | Модальное окно закрывается без выбора элемента. Исходное поле View picker остаётся в прежнем состоянии. |
| **Постусловия** | Нет |
