# Баг-репорт: Некорректное обновление View display после удаления элемента

| Поле | Значение |
|------|----------|
| **ID** | BUG-004 |
| **Приоритет** | High |
| **Серьёзность** | Critical |
| **Компонент** | ViewDisplay, ViewPicker (модульные представления) |
| **Версия** | 5.0.1-63d86ab |
| **Окружение** | Мобильное приложение (Android/iOS) |
| **Статус** | Новый |
| **Автор** | Алексей Луценко |
| **Дата обнаружения** | 2026-08-04 |

---

## 🐛 Описание

После удаления элемента через `ViewPicker` поле `ViewDisplay` не обновляется автоматически. Элемент остаётся в списке до ручного обновления страницы или перезахода в раздел.

---

## 🔍 Шаги воспроизведения

| Шаг | Действие |
|-----|----------|
| 1 | Запустить мобильное приложение на устройстве/эмуляторе. |
| 2 | В поле URL указать тенант: `check-modals.app.ru`. |
| 3 | Залогиниться, используя данные для авторизации из **Passbolt**. |
| 4 | Перейти в раздел **"Замечания"**. |
| 5 | Создать новый ФИ. |
| 6 | В поле **"Объект"** нажать кнопку **"Выбрать"** и добавить элемент. |
| 7 | Убедиться, что элемент отобразился в `ViewDisplay`. |
| 8 | Открыть `ViewPicker`, выбрать другой элемент или удалить существующий. |
| 9 | Обратить внимание на состояние `ViewDisplay` после удаления. |

---

## ✅ Ожидаемый результат

После удаления элемента через `ViewPicker`:
1. `ViewDisplay` мгновенно обновляется.
2. Удалённый элемент исчезает из списка.
3. Появляется заглушка "Ничего не выбрано" (если список пуст).
4. Обновление происходит без перезагрузки страницы.

---

## ❌ Текущий результат

1. `ViewDisplay` не обновляется после удаления элемента.
2. Удалённый элемент остаётся в списке визуально.
3. При попытке взаимодействия с удалённым элементом возникает ошибка (элемент не найден).
4. Только после ручного обновления состояние становится корректным.
