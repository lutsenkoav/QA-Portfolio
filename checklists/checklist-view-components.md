## 1. ListView (Представление в виде списка)

### 1.1. Must have

| # | Тест-кейс | Шаги | Ожидаемый результат |
|---|-----------|-------|----------------------|
| 1.1.1 | **Отображение информации из map.ts: description** | 1. Открыть ListView с элементами, у которых в map.ts заполнен description (текст, дата). | В строке каждого элемента списка в блоке описания отображается: текст и дата согласно маппингу. |
| 1.1.2 | **Отображение информации из map.ts: chips** | 1. Открыть ListView с элементами, у которых в map.ts настроены chips. | В строке элемента отображаются 4 чипса. В каждом чипсе корректно отображается: текстовая информация, дата (в верном формате), иконка. |
| 1.1.3 | **Отображение информации из map.ts: link** | 1. Найти элемент с настроенной ссылкой (link). 2. Кликнуть по ссылке. | Ссылка отображается как кликабельный элемент. При клике происходит переход по указанному URL (или открывается связанный объект). |
| 1.1.4 | **Отображение информации из map.ts: fields (окно с информацией о ФИ)** | 1. Навести курсор на любой ФИ (Form Instance) в списке. 2. Нажать клавишу `i` (или другую заданную). | Отображается всплывающее окно с информацией о ФИ. Данные выводятся из полей формы, указанных в map.ts. |
| 1.1.5 | **Отображение информации из map.ts: fields (смена ФИ)** | 1. Навести курсор на другой ФИ. | Информация во всплывающем окне динамически меняется на данные выбранного ФИ. |
| 1.1.6 | **Отображение информации из map.ts: fields (пустые поля)** | 1. Навести курсор на ФИ, у которого одно из полей, указанных в map.ts, не заполнено. | На месте пустого поля отображается плейсхолдер (например, "—" или "Не указано"). |
| 1.1.7 | **Отображение информации из map.ts: fields (скрытие окна)** | 1. При открытом окне информации о ФИ повторно нажать клавишу `i`. | Всплывающее окно с информацией закрывается. |
| 1.1.8 | **Отображение информации из map.ts: url (для документооборота)** | 1. Найти элемент с полем url. 2. Кликнуть по элементу. | Происходит выбор элемента (открытие связанного документа/записи) согласно бизнес-логике. |
| 1.2.1 | **Выделение элемента кликом на чекбокс** | 1. Кликнуть по чекбоксу любого элемента в списке. | Элемент выделяется (чекбокс становится отмеченным). В нижней части экрана появляется меню действий (панель с кнопками). |
| 1.2.2 | **Выделение элемента (отсутствие меню при ПКМ)** | 1. Выделить один или несколько элементов в списке. 2. Кликнуть ПКМ по любому выделенному элементу. | Меню действий (контекстное меню, вызываемое ПКМ) не появляется. Выделение сохраняется. |
| 1.2.3 | **Выделение элемента (кнопка "Выбрать все")** | 1. В нижнем меню действий нажать кнопку "Выбрать все". | Выделяются все элементы на текущей странице списка (или во всем списке, согласно логике). Кнопка меняет состояние на "Снять все". |
| 1.2.4 | **Выделение элемента (кнопка "Снять все")** | 1. После активации "Выбрать все", нажать эту же кнопку (которая теперь называется "Снять все"). | Выделение со всех элементов снимается. Нижнее меню действий пропадает. |
| 1.2.5 | **Снятие выделения с элемента** | 1. Кликнуть по чекбоксу уже выделенного элемента. | Выделение с этого элемента снимается (чекбокс становится пустым). |

### 1.2. Should have

| # | Тест-кейс | Шаги | Ожидаемый результат |
|---|-----------|-------|----------------------|
| 1.3.1 | **Отображение текста для пустого списка (emptyList)** | 1. Открыть ListView с фильтром, который гарантированно не возвращает ни одного элемента. 2. (Или зайти в раздел, где список должен быть пуст). | Отображается кастомное сообщение, заданное в настройках (emptyList) или переменных (variables). |
| 1.3.2 | **Пагинация** | 1. Открыть список, содержащий больше элементов, чем может поместиться на одной странице. | Отображаются элементы управления пагинацией (номера страниц, стрелки "Вперед/Назад"). При переключении страниц список обновляется. |
| 1.4.1 | **Действия ПКМ: Выбрать** | 1. Кликнуть ПКМ по элементу (не выделенному). 2. В контекстном меню выбрать действие "Выбрать". | Элемент выделяется. |
| 1.4.2 | **Действия ПКМ: Удалить** | 1. Выделить элемент. 2. Кликнуть ПКМ по нему и выбрать "Удалить". | Отображается диалог подтверждения. При подтверждении элемент удаляется из списка (и из системы). |
| 1.4.3 | **Действия ПКМ: Сформировать документ** | 1. Выделить элемент. 2. Кликнуть ПКМ по нему и выбрать "Сформировать документ". | Запускается процесс формирования документа (генерируется PDF, создается связанный документ и т.д.). |
| 1.5.1 | **Действия нижнего меню (консоль)** | 1. Выделить один или несколько элементов. 2. В нижнем меню выбрать действие. | Выбранное действие (например, "Удалить", "Экспортировать", "Изменить статус") выполняется для всех выделенных элементов. |
| 1.6.1 | **Горячие клавиши на списке** | 1. Использовать заданные горячие клавиши (например, `Ctrl+A` - выделить все, `Del` - удалить). | Соответствующие действия выполняются корректно. |
| 1.6.2 | **Горячие клавиши в меню действий** | 1. После открытия меню действий (или вызова контекстного меню), использовать клавиши быстрого доступа (например, цифры `1`, `2`, `3` для выбора пунктов меню). | Соответствующие пункты меню активируются. |
| 1.7.1 | **Снятие выделения кликом вне элемента** | 1. Выделить один или несколько элементов. 2. Кликнуть на пустую область списка (мимо элементов). | Выделение со всех элементов снимается. Нижнее меню действий пропадает. |

## 2. TreeView (Представление в виде дерева)

### 2.1. Must have

| # | Тест-кейс | Шаги | Ожидаемый результат |
|---|-----------|-------|----------------------|
| 2.1.1 | **Отображение элементов справочника в свернутом состоянии** | 1. Открыть TreeView с данными. | Все корневые элементы отображаются в свернутом виде. Справа от названия отображается иконка "развернуть" (например, стрелка или "+"). |
| 2.1.2 | **Разворачивание и сворачивание элемента (открытие ФИ)** | 1. Нажать на иконку "развернуть" у любого корневого элемента. | Элемент разворачивается, показывая своих дочерних элементов (подпапки, документы). При повторном клике элемент сворачивается. |
| 2.1.3 | **Отображение дочерних элементов** | 1. Развернуть несколько уровней дерева. | Все дочерние элементы отображаются с корректным отступом (иерархией). Названия и иконки соответствуют типам элементов (папка, документ, форма). |
| 2.1.4 | **Отображение информации из map.ts (icon, title, description)** | 1. Навести курсор на любой элемент дерева. 2. (Если предусмотрено) Отобразить tooltip. | У элемента есть иконка, заголовок (title) и, возможно, подсказка (description), соответствующие данным из map.ts. |
| 2.1.5 | **Отображение пустой папки** | 1. Развернуть элемент, у которого нет дочерних элементов. | Дочерние элементы не отображаются. Элемент выглядит как "пустая папка" (обычно без стрелки разворота или с другим стилем). |
| 2.1.6 | **Выбор элемента** | 1. Кликнуть по заголовку (названию) любого элемента в дереве. | Элемент выделяется (становится активным). В зависимости от логики, содержимое выделенного элемента может отображаться в соседней панели. |

### 2.2. Should have

| # | Тест-кейс | Шаги | Ожидаемый результат |
|---|-----------|-------|----------------------|
| 2.2.1 | **Состояния disabled и readOnly** | 1. Найти элемент с атрибутом disabled или readOnly. 2. Попытаться выполнить с ним действия. | **disabled:** Элемент неактивен (серый), его нельзя развернуть, выбрать или перемещать. **readOnly:** Элемент можно выбрать, но нельзя редактировать, удалять или перемещать. |
| 2.2.2 | **Пагинация для дочерних элементов** | 1. Развернуть папку, которая содержит более N дочерних элементов (где N - лимит на страницу). | Внутри развернутой папки отображается пагинация для списка дочерних элементов. Переключение страниц работает корректно. |
| 2.2.3 | **Дочерний элемент без стрелки** | 1. Найти дочерний элемент, который, согласно логике, не может содержать потомков. | У такого элемента отсутствует иконка "развернуть" (стрелка) справа. |
| 2.2.4 | **Открытие ФИ в TreeView** | 1. Дважды кликнуть по элементу-документу (или выбрать пункт "Открыть" в контекстном меню). | Открывается форма (Form Instance) этого документа в новом окне/вкладке или в основной рабочей области. |
| 2.2.5 | **Drag and Drop (перетаскивание)** | 1. Захватить элемент и перетащить его на другой элемент. | Элемент перемещается в указанную папку (становится дочерним). При этом должно появляться визуальное подтверждение (подсветка, анимация). |
| 2.2.6 | **Поиск/фильтрация в дереве** | 1. В поле поиска ввести название элемента. | Дерево схлопывается до найденных элементов. Корневые элементы, не содержащие искомого, могут быть скрыты. |
| 2.2.7 | **Множественный выбор (с Ctrl/Shift)** | 1. Выделить несколько элементов, используя клавиши `Ctrl` (для выбора нескольких отдельных) и `Shift` (для выбора диапазона). | Выделены все указанные элементы. Возможно применение массовых действий к выделенным элементам. |

## 3. View display (Поле для отображения элементов другого представления)

| # | Тест-кейс | Шаги | Ожидаемый результат |
|---|-----------|-------|----------------------|
| 3.1 | **Отображение связанных элементов** | 1. Открыть форму, содержащую поле "View display". | В поле отображается список элементов, связанных с текущим ФИ, в соответствии с заданным представлением (ListView, TreeView, GridView). |
| 3.2 | **Переход по ссылке** | 1. Внутри поля "View display" кликнуть по элементу. | Происходит переход к связанному ФИ (открывается его карточка). |
| 3.3 | **Отображение иконок и статусов** | 1. Найти элемент в View display с иконкой/статусом. | Иконка и статус корректно отображаются в строке элемента. |
| 3.4 | **Обновление при изменении данных** | 1. Внести изменения в данные, которые должны отображаться в View display (например, добавить новый связанный документ). 2. Обновить страницу или дождаться автообновления. | Список в поле "View display" автоматически или после обновления отображает актуальные данные. |
| 3.5 | **Отображение пустого состояния** | 1. Открыть форму, у которой нет связанных элементов для отображения в View display. | В поле отображается текст-заглушка, например, "Нет связанных элементов". |

## 4. View picker (Поле для добавления элементов из другого представления)

| # | Тест-кейс | Шаги | Ожидаемый результат |
|---|-----------|-------|----------------------|
| 4.1 | **Открытие модального окна выбора** | 1. Нажать на кнопку "Выбрать" (или иконку) внутри поля "View picker". | Открывается модальное окно с представлением (ListView/TreeView) для выбора элемента. |
| 4.2 | **Поиск и фильтрация в модальном окне** | 1. В модальном окне использовать поле поиска или фильтры. | Список элементов фильтруется в соответствии с поисковым запросом. |
| 4.3 | **Выбор элемента и заполнение поля** | 1. В модальном окне выбрать один элемент. | Модальное окно закрывается. В поле "View picker" отображается выбранный элемент (его название, код). |
| 4.4 | **Добавление нескольких элементов (Multi-picker)** | 1. В модальном окне выбрать несколько элементов (если это предусмотрено). 2. Нажать "Применить". | В поле "View picker" отображаются все выбранные элементы (списком или через разделители). |
| 4.5 | **Очистка поля (снятие выбора)** | 1. Нажать на крестик (или кнопку "Очистить") рядом с выбранным элементом в поле "View picker". | Выбранный элемент удаляется из поля. |
| 4.6 | **Отображение уже выбранных элементов в модальном окне** | 1. Открыть модальное окно, когда в поле View picker уже выбран элемент. | Ранее выбранный элемент в модальном окне подсвечен (отмечен). |
| 4.7 | **Проверка обязательности заполнения поля** | 1. Если поле View picker обязательно для заполнения, отправить форму, оставив его пустым. | Отображается сообщение об ошибке валидации, форма не отправляется. |
| 4.8 | **Отображение выбранного элемента только для чтения** | 1. Найти форму, где View picker находится в режиме "только для чтения". | Поле отображает выбранный элемент, но кнопка выбора неактивна или отсутствует. |
