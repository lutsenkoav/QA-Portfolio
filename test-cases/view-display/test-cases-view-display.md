## Легенда

| Приоритет | Описание |
|-----------|----------|
| **High** | Критичные кейсы. Без их выполнения функциональность не может быть выпущена в релиз. |
| **Medium** | Важные кейсы. Должны быть выполнены до релиза, но при необходимости могут быть перенесены. |

## 1. Отображение связанных элементов

| **TC-ViewDisplay-001** | |
|------------------------|---|
| **Название** | Проверка отображения связанных элементов в поле View display |
| **Приоритет** | High |
| **Предусловия** | 1. Открыта форма, содержащая поле "View display".<br>2. У текущего ФИ есть связанные элементы. |
| **Шаги** | 1. Обратить внимание на содержимое поля View display. |
| **Ожидаемый результат** | В поле отображается список элементов, связанных с текущим ФИ, в соответствии с заданным представлением (ListView, TreeView, GridView). |
| **Постусловия** | Нет |

---

## 2. Переход по ссылке

| **TC-ViewDisplay-002** | |
|------------------------|---|
| **Название** | Проверка перехода по ссылке из поля View display |
| **Приоритет** | High |
| **Предусловия** | 1. Открыта форма с полем View display (TC-ViewDisplay-001).<br>2. В поле есть элементы. |
| **Шаги** | 1. Кликнуть по любому элементу внутри поля View display. |
| **Ожидаемый результат** | Происходит переход к связанному ФИ (открывается его карточка или форма). |
| **Постусловия** | Вернуться на исходную форму. |

---

## 3. Иконки и статусы

| **TC-ViewDisplay-003** | |
|------------------------|---|
| **Название** | Проверка отображения иконок и статусов в поле View display |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыта форма с полем View display.<br>2. В поле есть элементы с иконками и статусами. |
| **Шаги** | 1. Найти элемент с иконкой/статусом.<br>2. Обратить внимание на их отображение. |
| **Ожидаемый результат** | Иконка и статус корректно отображаются в строке элемента. Они соответствуют данным из маппинга. |
| **Постусловия** | Нет |

---

## 4. Обновление данных

| **TC-ViewDisplay-004** | |
|------------------------|---|
| **Название** | Проверка обновления поля View display при изменении данных |
| **Приоритет** | High |
| **Предусловия** | 1. Открыта форма с полем View display.<br>2. У текущего ФИ есть связанные элементы. |
| **Шаги** | 1. Добавить новый связанный элемент (через View picker или другим способом).<br>2. Обновить страницу или дождаться автообновления. |
| **Ожидаемый результат** | Список в поле View display автоматически или после обновления отображает актуальные данные, включая новый элемент. |
| **Постусловия** | Нет |

---

## 5. Пустое состояние

| **TC-ViewDisplay-005** | |
|------------------------|---|
| **Название** | Проверка отображения пустого состояния в поле View display |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыта форма, у которой нет связанных элементов для отображения в View display. |
| **Шаги** | 1. Обратить внимание на поле View display. |
| **Ожидаемый результат** | В поле отображается текст-заглушка, например: "Нет связанных элементов", "—" или другой заданный плейсхолдер. |
| **Постусловия** | Нет |
