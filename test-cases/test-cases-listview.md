## Легенда

| Приоритет | Описание |
|-----------|----------|
| **High** | Критичные кейсы. Без их выполнения функциональность не может быть выпущена в релиз. |
| **Medium** | Важные кейсы. Должны быть выполнены до релиза, но при необходимости могут быть перенесены. |
| **Low** | Кейсы для edge-случаев. Могут быть выполнены после релиза. |

| **Ожидаемый результат** | На месте пустого поля отображается плейсхолдер (например, "—" или "Не указано"). |

## 2. Выделение элементов списка

### 2.1. Выделение через чекбокс

| **TC-ListView-010** | |
|----------------------|---|
| **Название** | Проверка выделения элемента кликом на чекбокс |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Нижнее меню действий скрыто. |
| **Шаги** | 1. Кликнуть по чекбоксу любого элемента в списке. |
| **Ожидаемый результат** | 1. Элемент выделяется (чекбокс становится отмеченным).<br>2. В нижней части экрана появляется меню действий (панель с кнопками). |
| **Постусловия** | Снять выделение. |

| **TC-ListView-011** | |
|----------------------|---|
| **Название** | Проверка отсутствия меню при ПКМ по выделенному элементу |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Один элемент выделен (TC-ListView-010). |
| **Шаги** | 1. Кликнуть ПКМ по любому выделенному элементу. |
| **Ожидаемый результат** | Контекстное меню (вызываемое ПКМ) не появляется. Выделение сохраняется. |
| **Постусловия** | Снять выделение. |

---

### 2.2. Массовое выделение

| **TC-ListView-012** | |
|----------------------|---|
| **Название** | Проверка выделения всех элементов через кнопку "Выбрать все" |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Выделен хотя бы один элемент (меню действий активно). |
| **Шаги** | 1. В нижнем меню действий нажать кнопку "Выбрать все". |
| **Ожидаемый результат** | 1. Выделяются все элементы на текущей странице (или во всём списке согласно логике).<br>2. Кнопка меняет состояние на "Снять все". |
| **Постусловия** | Снять выделение. |

| **TC-ListView-013** | |
|----------------------|---|
| **Название** | Проверка снятия выделения через кнопку "Снять все" |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Все элементы выделены (TC-ListView-012). |
| **Шаги** | 1. Нажать кнопку "Снять все". |
| **Ожидаемый результат** | 1. Выделение со всех элементов снимается.<br>2. Нижнее меню действий пропадает. |
| **Постусловия** | Нет |

## 3. Пагинация

| **TC-ListView-016** | |
|----------------------|---|
| **Название** | Проверка отображения элементов пагинации |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт ListView, содержащий больше элементов, чем помещается на одной странице. |
| **Шаги** | 1. Прокрутить список до конца.<br>2. Обратить внимание на наличие элементов управления пагинацией. |
| **Ожидаемый результат** | В нижней части списка отображаются: номера страниц, стрелки "Вперед"/"Назад", информация о количестве элементов. |
| **Постусловия** | Нет |

| **TC-ListView-017** | |
|----------------------|---|
| **Название** | Проверка переключения страниц |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с пагинацией (TC-ListView-016). |
| **Шаги** | 1. Нажать на номер следующей страницы (например, "2").<br>2. Нажать на стрелку "Вперед".<br>3. Нажать на стрелку "Назад". |
| **Ожидаемый результат** | 1. При клике на номер страницы список обновляется, отображаются элементы выбранной страницы.<br>2. Кнопки "Вперед"/"Назад" работают корректно, переключая страницы. |
| **Постусловия** | Нет |

| **TC-ListView-018** | |
|----------------------|---|
| **Название** | Проверка пагинации при переходе на последнюю страницу |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт ListView с пагинацией (TC-ListView-016). |
| **Шаги** | 1. Перейти на последнюю страницу.<br>2. Обратить внимание на состояние кнопки "Вперед". |
| **Ожидаемый результат** | Кнопка "Вперед" становится неактивной (серой). Отображаются элементы последней страницы. |
| **Постусловия** | Нет |

## 4. Контекстное меню (ПКМ)

| **TC-ListView-019** | |
|----------------------|---|
| **Название** | Проверка вызова контекстного меню ПКМ |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Ни один элемент не выделен. |
| **Шаги** | 1. Кликнуть ПКМ по любому элементу в списке. |
| **Ожидаемый результат** | Отображается контекстное меню со списком доступных действий (например: "Выбрать", "Удалить", "Сформировать документ"). |
| **Постусловия** | Закрыть меню (клик вне меню). |

| **TC-ListView-020** | |
|----------------------|---|
| **Название** | Проверка действия "Выбрать" через контекстное меню |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Ни один элемент не выделен. |
| **Шаги** | 1. Кликнуть ПКМ по элементу.<br>2. В контекстном меню выбрать действие "Выбрать". |
| **Ожидаемый результат** | Элемент выделяется (чекбокс становится отмеченным). Появляется нижнее меню действий. |
| **Постусловия** | Снять выделение. |

| **TC-ListView-021** | |
|----------------------|---|
| **Название** | Проверка действия "Удалить" через контекстное меню |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Элемент выделен (TC-ListView-010). |
| **Шаги** | 1. Кликнуть ПКМ по выделенному элементу.<br>2. В контекстном меню выбрать действие "Удалить". |
| **Ожидаемый результат** | 1. Отображается диалог подтверждения удаления.<br>2. При подтверждении элемент удаляется из списка и из системы.<br>3. При отмене элемент остаётся в списке. |
| **Постусловия** | Нет |

| **TC-ListView-022** | |
|----------------------|---|
| **Название** | Проверка действия "Сформировать документ" через контекстное меню |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Элемент выделен (TC-ListView-010). |
| **Шаги** | 1. Кликнуть ПКМ по выделенному элементу.<br>2. В контекстном меню выбрать действие "Сформировать документ". |
| **Ожидаемый результат** | Запускается процесс формирования документа: генерируется PDF, создается связанный документ или открывается форма создания. |
| **Постусловия** | Нет |

## 5. Нижнее меню действий

| **TC-ListView-023** | |
|----------------------|---|
| **Название** | Проверка выполнения действий из нижнего меню (консоль) |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Выделен один или несколько элементов (меню активно). |
| **Шаги** | 1. В нижнем меню выбрать действие (например, "Удалить", "Экспортировать", "Изменить статус").<br>2. Подтвердить действие, если требуется. |
| **Ожидаемый результат** | Выбранное действие выполняется для всех выделенных элементов. В случае успеха отображается уведомление. |
| **Постусловия** | Нет |

| **TC-ListView-024** | |
|----------------------|---|
| **Название** | Проверка закрытия нижнего меню при снятии всех выделений |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Выделен один или несколько элементов (меню активно). |
| **Шаги** | 1. Снять выделение со всех элементов (например, кликнуть вне списка или снять чекбоксы). |
| **Ожидаемый результат** | Нижнее меню действий автоматически скрывается. |
| **Постусловия** | Нет |

## 6. Горячие клавиши

| **TC-ListView-025** | |
|----------------------|---|
| **Название** | Проверка горячих клавиш для выделения всех элементов (Ctrl+A) |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Нижнее меню действий скрыто. |
| **Шаги** | 1. Нажать комбинацию клавиш `Ctrl+A` (или `Cmd+A` на Mac). |
| **Ожидаемый результат** | Выделяются все элементы на текущей странице (или во всём списке). Появляется нижнее меню действий. |
| **Постусловия** | Снять выделение. |

| **TC-ListView-026** | |
|----------------------|---|
| **Название** | Проверка горячих клавиш для удаления элемента (Del) |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Выделен один элемент. |
| **Шаги** | 1. Нажать клавишу `Del` (или `Delete`). |
| **Ожидаемый результат** | 1. Отображается диалог подтверждения удаления.<br>2. При подтверждении элемент удаляется. |
| **Постусловия** | Нет |

| **TC-ListView-027** | |
|----------------------|---|
| **Название** | Проверка горячих клавиш в меню действий |
| **Приоритет** | Low |
| **Предусловия** | 1. Открыт ListView с элементами.<br>2. Выделен один или несколько элементов (меню активно).<br>3. В меню действий есть пункты с цифровыми обозначениями (1, 2, 3). |
| **Шаги** | 1. Нажать клавишу `1` (или другую, соответствующую пункту меню). |
| **Ожидаемый результат** | Соответствующий пункт меню активируется. Выполняется действие. |
| **Постусловия** | Нет |

## 7. Пустые состояния

| **TC-ListView-028** | |
|----------------------|---|
| **Название** | Проверка отображения пустого списка (emptyList) |
| **Приоритет** | Medium |
