# Подготовка изолированной среды для тестирования

## 📌 Цель документа

Описать процесс развёртывания изолированного тестового стенда для проверки модульных представлений (ListView, TreeView, View display, View picker) в мобильном приложении.

---

## 🛠️ Предварительные требования

- Доступ к Jenkins (сборка мета-чарта)
- Доступ к Passbolt (учётные данные)
- Доступ к репозиторию с конфигурациями
- Установленный Git и CLI для сборки

---

## 🚀 Подготовка среды

### 1. Поднять новый тенант

Запустить джобу **"Удобное создание тенанта"** в Jenkins.

> **Результат:** Создан новый изолированный тенант с уникальным идентификатором.

---

### 2. Собрать мета-чарт

Собрать `meta-chart` со следующей конфигурацией:

- **Версия модульных компонентов:** `5.0.1-63d86ab`
- **Версии сервисов:** последние релизные

> **Результат:** Собран артефакт для деплоя.

---

### 3. Задеплоить новый инстанс

Выполнить деплой нового инстанса из собранного мета-чарта.

> **Результат:** Инстанс развёрнут и готов к переключению тенанта.

---

### 4. Переключить тенант на новый инстанс

Выполнить переключение созданного тенанта на только что развёрнутый инстанс.

> **Результат:** Тенант привязан к новому инстансу.

---

### 5. Залить конфигурацию

Залить на новый тенант версию конфигурации с добавленными данными по модульным компонентам:

- **Версия конфигурации:** `new_modals`

> **Результат:** В системе доступны данные для тестирования модульных представлений.

---

### 6. Собрать мобильное приложение

Собрать `Launcher` и `Bundle URL` мобильного приложения из ветки: `fix/modals`

# команда для сборки
npm run build:android --branch=fix/modals
