# Баг-репорт: Не удаляется выбранный элемент из списка в компоненте ViewDisplay

| Поле | Значение |
|------|----------|
| **ID** | BUG-001 |
| **Приоритет** | High |
| **Серьёзность** | Critical |
| **Компонент** | ViewDisplay (модульные представления) |
| **Версия** | 5.0.1-63d86ab |
| **Окружение** | Мобильное приложение (Android/iOS) |
| **Статус** | Новый |
| **Автор** | Алексей Луценко |
| **Дата обнаружения** | 2026-08-04 |

---

## 🐛 Описание

При попытке удалить выбранный элемент из списка в компоненте `ViewDisplay` через иконку-крестик элемент не удаляется. Ожидается, что элемент исчезнет из списка, а на его месте появится заглушка "Ничего не выбрано".

---

## 🔍 Шаги воспроизведения

| Шаг | Действие |
|-----|----------|
| 1 | Собрать Launcher и Bundle URL мобильного приложения из ветки `fix/modals`. |
| 2 | Запустить мобильное приложение на устройстве/эмуляторе. |
| 3 | В поле URL указать тенант: `check-modals.app.ru`. |
| 4 | Залогиниться, используя данные для авторизации из **Passbolt**. |
| 5 | Перейти в раздел **"Замечания"**. |
| 6 | Создать новый ФИ (Form Instance). |
| 7 | В поле **"Объект"** нажать кнопку **"Выбрать"**. |
| 8 | Выбрать любой элемент из списка. |
| 9 | Удалить выбранный элемент, нажав на иконку-крестик. |

---

## ✅ Ожидаемый результат

Выбранный элемент удаляется из списка. На его месте отображается заглушка **"Ничего не выбрано"**.

---

## ❌ Текущий результат

Выбранный элемент **не удаляется**. Он остаётся в списке, иконка-крестик не выполняет никакого действия.
