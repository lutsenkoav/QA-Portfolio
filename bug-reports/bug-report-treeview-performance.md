# Баг-репорт: Долгая загрузка TreeView с большим количеством элементов

| Поле | Значение |
|------|----------|
| **ID** | BUG-003 |
| **Приоритет** | High |
| **Серьёзность** | Major |
| **Компонент** | TreeView (модульные представления) |
| **Версия** | 5.0.1-63d86ab |
| **Окружение** | Мобильное приложение (Android/iOS) |
| **Статус** | Новый |
| **Автор** | Алексей Луценко |
| **Дата обнаружения** | 2026-08-04 |

---

## 🐛 Описание

При открытии раздела с TreeView, содержащего более 1000 элементов (папок и документов), наблюдается **задержка загрузки более 10 секунд**. Приложение "зависает" на 2-3 секунды при разворачивании глубоких папок (5+ уровней вложенности).

---

## 🔍 Шаги воспроизведения

| Шаг | Действие |
|-----|----------|
| 1 | Запустить мобильное приложение на устройстве/эмуляторе. |
| 2 | В поле URL указать тенант: `check-modals.app.ru`. |
| 3 | Залогиниться, используя данные для авторизации из **Passbolt**. |
| 4 | Перейти в раздел с TreeView, содержащим 1000+ элементов. |
| 5 | Засечь время загрузки дерева. |
| 6 | Развернуть папку 5-го уровня вложенности. |
| 7 | Засечь время разворачивания. |

---

## ✅ Ожидаемый результат

1. Дерево загружается **не более 2 секунд**.
2. Разворачивание папки происходит **мгновенно (до 0.5 секунд)**.
3. Приложение не "зависает" во время загрузки.
4. Отображается индикатор загрузки (Spinner) на время загрузки.

---

## ❌ Текущий результат

1. Время загрузки дерева — **более 10 секунд** (замерено: 12.4 сек).
2. Разворачивание папки 5-го уровня — **более 2 секунд** (замерено: 2.8 сек).
3. Приложение "зависает" на 2-3 секунды, UI не реагирует на действия.
4. Индикатор загрузки отсутствует.

---

## 📊 Метрики производительности

| Метрика | Текущее значение | Ожидаемое значение |
|---------|------------------|-------------------|
| **Время загрузки дерева (1000+ элементов)** | 12.4 сек | ≤ 2 сек |
| **Время разворачивания папки (5+ уровней)** | 2.8 сек | ≤ 0.5 сек |
| **Задержка UI (зависание)** | 2-3 сек | 0 сек |
| **Наличие индикатора загрузки** | Нет | Да |

---

## 🔬 Дополнительные наблюдения

- Проблема усиливается на устройствах с меньшим объёмом оперативной памяти (3 ГБ и менее).
- В режиме полёта (без сети) время загрузки незначительно сокращается (~0.5 сек), что указывает на проблему на стороне клиента (рендеринг), а не на задержки сети.
- При скролле дерева также наблюдаются микрозадержки (дропы кадров).
