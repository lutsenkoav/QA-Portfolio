## Легенда

| Приоритет | Описание |
|-----------|----------|
| **High** | Критичные кейсы. Без их выполнения функциональность не может быть выпущена в релиз. |
| **Medium** | Важные кейсы. Должны быть выполнены до релиза, но при необходимости могут быть перенесены. |
| **Low** | Кейсы для edge-случаев. Могут быть выполнены после релиза. |

## 1. Отображение дерева

| **TC-TreeView-001** | |
|----------------------|---|
| **Название** | Проверка отображения дерева в свернутом состоянии |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть корневые элементы. |
| **Шаги** | 1. Обратить внимание на отображение корневых элементов. |
| **Ожидаемый результат** | Все корневые элементы отображаются в свернутом виде. Справа от названия отображается иконка "развернуть" (стрелка, "+" или треугольник). |
| **Постусловия** | Нет |

| **TC-TreeView-002** | |
|----------------------|---|
| **Название** | Проверка разворачивания элемента дерева |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт TreeView с данными (TC-TreeView-001). |
| **Шаги** | 1. Нажать на иконку "развернуть" у любого корневого элемента. |
| **Ожидаемый результат** | Элемент разворачивается. Отображаются его дочерние элементы (подпапки, документы, формы). Иконка "развернуть" меняется на "свернуть". |
| **Постусловия** | Свернуть элемент. |

| **TC-TreeView-003** | |
|----------------------|---|
| **Название** | Проверка сворачивания элемента дерева |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. Элемент развернут (TC-TreeView-002). |
| **Шаги** | 1. Нажать на иконку "свернуть" у развернутого элемента. |
| **Ожидаемый результат** | Элемент сворачивается. Дочерние элементы скрываются. Иконка меняется обратно на "развернуть". |
| **Постусловия** | Нет |

| **TC-TreeView-004** | |
|----------------------|---|
| **Название** | Проверка отображения дочерних элементов с корректной иерархией |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт TreeView с данными, имеющими несколько уровней вложенности. |
| **Шаги** | 1. Развернуть корневой элемент.<br>2. Развернуть дочерний элемент.<br>3. Развернуть элемент следующего уровня. |
| **Ожидаемый результат** | Все дочерние элементы отображаются с корректным отступом (иерархией). Названия и иконки соответствуют типам элементов (папка, документ, форма). |
| **Постусловия** | Свернуть все элементы. |

| **TC-TreeView-005** | |
|----------------------|---|
| **Название** | Проверка отображения информации из map.ts (icon, title, description) |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В map.ts для элементов настроены icon, title, description. |
| **Шаги** | 1. Навести курсор на любой элемент дерева (если предусмотрен tooltip).<br>2. Обратить внимание на иконку и название элемента. |
| **Ожидаемый результат** | 1. У каждого элемента есть иконка, соответствующая его типу (папка, документ, форма).<br>2. Отображается корректный заголовок (title).<br>3. При наведении (если есть tooltip) отображается description. |
| **Постусловия** | Нет |

| **TC-TreeView-006** | |
|----------------------|---|
| **Название** | Проверка отображения пустой папки |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. Есть элемент (папка), у которого нет дочерних элементов. |
| **Шаги** | 1. Развернуть пустую папку. |
| **Ожидаемый результат** | 1. Папка разворачивается, но дочерние элементы не отображаются.<br>2. Визуально папка выглядит как "пустая" (обычно без стрелки разворота или с другим стилем). |
| **Постусловия** | Свернуть папку. |

## 2. Работа с элементами дерева

| **TC-TreeView-007** | |
|----------------------|---|
| **Название** | Проверка выбора элемента в дереве |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт TreeView с данными. |
| **Шаги** | 1. Кликнуть по заголовку (названию) любого элемента в дереве. |
| **Ожидаемый результат** | 1. Элемент выделяется (становится активным).<br>2. В зависимости от логики, содержимое выделенного элемента отображается в соседней панели или открывается в новой вкладке. |
| **Постусловия** | Снять выделение (если возможно). |

| **TC-TreeView-008** | |
|----------------------|---|
| **Название** | Проверка открытия ФИ из TreeView |
| **Приоритет** | High |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть элемент-документ (Form Instance). |
| **Шаги** | 1. Дважды кликнуть по элементу-документу.<br>2. Или кликнуть ПКМ и выбрать пункт "Открыть". |
| **Ожидаемый результат** | Открывается форма (Form Instance) этого документа в новом окне/вкладке или в основной рабочей области. |
| **Постусловия** | Закрыть открытую форму. |

| **TC-TreeView-009** | |
|----------------------|---|
| **Название** | Проверка наличия стрелки разворота только у элементов с дочерними |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть элементы как с дочерними, так и без. |
| **Шаги** | 1. Найти дочерний элемент, который не может содержать потомков (по логике).<br>2. Обратить внимание на наличие иконки "развернуть" у такого элемента. |
| **Ожидаемый результат** | У элемента, который не может содержать потомков, иконка "развернуть" (стрелка) отсутствует. |
| **Постусловия** | Нет |

| **TC-TreeView-010** | |
|----------------------|---|
| **Название** | Проверка множественного выбора элементов (Ctrl/Shift) |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть несколько элементов на одном уровне. |
| **Шаги** | 1. Выделить первый элемент.<br>2. Зажать клавишу `Ctrl` и выделить несколько других элементов.<br>3. Снять выделение.<br>4. Выделить первый элемент.<br>5. Зажать клавишу `Shift` и выделить последний элемент в списке. |
| **Ожидаемый результат** | 1. С `Ctrl` выделяются все выбранные элементы (по отдельности).<br>2. С `Shift` выделяется диапазон элементов от первого до последнего.<br>3. К выделенным элементам можно применить массовые действия (если предусмотрено). |
| **Постусловия** | Снять выделение. |

## 3. Состояния элементов

| **TC-TreeView-011** | |
|----------------------|---|
| **Название** | Проверка состояния disabled |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть элемент с атрибутом disabled. |
| **Шаги** | 1. Найти элемент с состоянием disabled.<br>2. Попытаться выполнить с ним действия: развернуть, выбрать, кликнуть ПКМ. |
| **Ожидаемый результат** | 1. Элемент визуально неактивен (серый, бледный).<br>2. Элемент нельзя развернуть, выбрать, перемещать.<br>3. Контекстное меню не вызывается. |
| **Постусловия** | Нет |

| **TC-TreeView-012** | |
|----------------------|---|
| **Название** | Проверка состояния readOnly |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть элемент с атрибутом readOnly. |
| **Шаги** | 1. Найти элемент с состоянием readOnly.<br>2. Попытаться выполнить с ним действия: выбрать, кликнуть ПКМ, перетащить. |
| **Ожидаемый результат** | 1. Элемент можно выбрать.<br>2. Элемент нельзя редактировать, удалять или перемещать.<br>3. Контекстное меню может быть ограничено (только чтение). |
| **Постусловия** | Нет |

## 4. Пагинация и поиск

| **TC-TreeView-013** | |
|----------------------|---|
| **Название** | Проверка пагинации для дочерних элементов |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть папка, содержащая более N дочерних элементов (где N - лимит на страницу). |
| **Шаги** | 1. Развернуть папку с большим количеством дочерних элементов.<br>2. Обратить внимание на наличие пагинации.<br>3. Переключить страницу. |
| **Ожидаемый результат** | 1. Внутри развернутой папки отображается пагинация для списка дочерних элементов.<br>2. Переключение страниц работает корректно, отображаются соответствующие элементы. |
| **Постусловия** | Свернуть папку. |

| **TC-TreeView-014** | |
|----------------------|---|
| **Название** | Проверка поиска/фильтрации в дереве |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть элементы с разными названиями. |
| **Шаги** | 1. В поле поиска ввести название существующего элемента.<br>2. Ввести частичное название.<br>3. Ввести несуществующее название. |
| **Ожидаемый результат** | 1. При вводе существующего названия дерево схлопывается до найденных элементов. Корневые элементы, не содержащие искомого, скрываются.<br>2. При частичном совпадении отображаются все подходящие элементы.<br>3. При несуществующем названии отображается сообщение "Ничего не найдено". |
| **Постусловия** | Очистить поле поиска. |

## 5. Drag and Drop

| **TC-TreeView-015** | |
|----------------------|---|
| **Название** | Проверка перетаскивания элемента (Drag and Drop) |
| **Приоритет** | Medium |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. В дереве есть как минимум два элемента на разных уровнях. |
| **Шаги** | 1. Захватить элемент (зажать левую кнопку мыши).<br>2. Перетащить его на другой элемент (папку).<br>3. Отпустить кнопку мыши. |
| **Ожидаемый результат** | 1. Во время перетаскивания отображается визуальное подтверждение (подсветка целевой папки, анимация).<br>2. Элемент перемещается в указанную папку (становится дочерним).<br>3. Дерево обновляется, отображая новую структуру. |
| **Постусловия** | Отменить перемещение (если возможно). |

| **TC-TreeView-016** | |
|----------------------|---|
| **Название** | Проверка Drag and Drop с отменой действия |
| **Приоритет** | Low |
| **Предусловия** | 1. Открыт TreeView с данными.<br>2. Начато перетаскивание элемента (TC-TreeView-015). |
| **Шаги** | 1. Перетащить элемент над целевой папкой, но отпустить кнопку мыши за пределами допустимой области. |
| **Ожидаемый результат** | Элемент возвращается на исходное место. Перемещение не происходит. |
| **Постусловия** | Нет |
