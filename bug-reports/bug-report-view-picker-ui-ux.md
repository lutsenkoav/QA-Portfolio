# Баг-репорт: Нечитаемый текст в поле View picker при длинном названии элемента

| Поле | Значение |
|------|----------|
| **ID** | BUG-002 |
| **Приоритет** | Medium |
| **Серьёзность** | Minor |
| **Компонент** | ViewPicker (модульные представления) |
| **Версия** | 5.0.1-63d86ab |
| **Окружение** | Мобильное приложение (Android/iOS) |
| **Статус** | Новый |
| **Автор** | Алексей Луценко |
| **Дата обнаружения** | 2026-08-04 |

---

## 🐛 Описание

При выборе элемента с длинным названием в поле `ViewPicker` текст обрезается и становится нечитаемым. Отсутствует tooltip или всплывающая подсказка с полным названием при наведении/длительном нажатии.

---

## 🔍 Шаги воспроизведения

| Шаг | Действие |
|-----|----------|
| 1 | Запустить мобильное приложение на устройстве/эмуляторе. |
| 2 | В поле URL указать тенант: `check-modals.app.ru`. |
| 3 | Залогиниться, используя данные для авторизации из **Passbolt**. |
| 4 | Перейти в раздел **"Замечания"**. |
| 5 | Создать новый ФИ. |
| 6 | В поле **"Объект"** нажать кнопку **"Выбрать"**. |
| 7 | Выбрать элемент с названием длиннее 30 символов (например, "Очень длинное название элемента, которое не помещается в поле"). |

---

## ✅ Ожидаемый результат

1. Название элемента отображается полностью или обрезается с троеточием (`...`).
2. При длительном нажатии на поле или наведении появляется всплывающая подсказка (tooltip) с полным названием.
3. Текст читаем, шрифт соответствует дизайн-системе.

---

## ❌ Текущий результат

1. Название элемента обрезается без троеточия (`...`).
2. Tooltip отсутствует.
3. Текст мелкий и сливается с фоном, что затрудняет чтение.
